### Практическая работа: Управление шаговым двигателем с обратной связью на ATmega328P

**Цель работы:** Изучить принцип работы биполярного шагового двигателя. Научиться управлять его скоростью и направлением вращения с помощью микроконтроллера ATmega328P, используя кнопки, АЦП (потенциометр) и отображая параметры на 7-сегментный индикатор.

**Используемое ПО и оборудование:**
*   **Среда разработки:** Atmel Studio 7.0 (или Microchip Studio).
*   **Моделирование:** Proteus 8 Professional.
*   **Микроконтроллер:** ATmega328P (тактовая частота 16 МГц, можно настроить внутреннюю или внешний кварц).
*   **Новый элемент:** Биполярный шаговый двигатель (например, 4-проводная модель из библиотеки Proteus) и драйвер к нему.

---

### Теоретическая часть

1.  **Что такое шаговый двигатель?**
    Это синхронный бесколлекторный двигатель, вал которого совершает не непрерывное вращение, а дискретные угловые перемещения — шаги. Количество шагов на один оборот строго фиксировано.
2.  **Биполярный шаговый двигатель.**
    Имеет две обмотки (4 провода). Для управления требуется менять полярность напряжения на обмотках, что усложняет драйвер, но дает больший крутящий момент по сравнению с униполярными.
3.  **Драйвер L293D (ключевой элемент схемы).**
    Микросхема представляет собой четыре полу-H-моста. Она позволяет:
    *   Управлять двумя обмотками с током до 600 мА на канал.
    *   Подавать на обмотки напряжение нужной полярности в зависимости от управляющих сигналов с МК.
    *   Использовать вывод `ENABLE` для ШИМ-управления током (в этой работе мы будем использовать его просто для включения двигателя).
4.  **Алгоритмы управления (последовательности коммутации).**
    Для управления 4-проводным биполярным двигателем через L293D, подключив обмотки к выходам драйвера, мы будем управлять 4-мя входами драйвера (IN1, IN2, IN3, IN4). Таблица истинности для одного полного шага:
    *   **Полношаговый режим (Full Step Mode).** Самый простой и надежный для начала.
        *   **Шаг 1:** Обмотка A: +, Обмотка B: + (биты: `0b1010`)
        *   **Шаг 2:** Обмотка A: -, Обмотка B: + (биты: `0b0110`)
        *   **Шаг 3:** Обмотка A: -, Обмотка B: - (биты: `0b0101`)
        *   **Шаг 4:** Обмотка A: +, Обмотка B: - (биты: `0b1001`)
    *   Для изменения направления вращения последовательность проходится в обратном порядке.

### Схема в Proteus (описание подключения)

1.  **Микроконтроллер:** Разместите на схеме `ATMEGA328P`.
2.  **Тактирование:** Подключите кварцевый резонатор 16 МГц и два конденсатора 22 пФ к выводам `XTAL1` (9) и `XTAL2` (10), или настройте внутренний генератор в свойствах МК.
3.  **Драйвер:** Разместите `L293D`.
    *   Питание двигателя `VCC2` (8) и логики `VCC1` (16) соедините вместе и подайте +5В.
    *   `ENABLE1` (1) и `ENABLE2` (9) соедините вместе и подключите к любой линии порта МК (например, `PD5`) для программного включения/выключения двигателя через подтяжку к +5В.
4.  **Подключение двигателя к драйверу:**
    *   Выходы драйвера `OUT1` (3) и `OUT2` (6) подключите к одной обмотке двигателя.
    *   Выходы `OUT3` (11) и `OUT4` (14) подключите ко второй обмотке.
5.  **Управляющие сигналы (МК -> Драйвер):**
    *   Подключите 4 линии порта МК, например `PB0`, `PB1`, `PB2`, `PB3`, ко входам драйвера `IN1` (2), `IN2` (7), `IN3` (10), `IN4` (15) соответственно.
6.  **Органы управления:**
    *   **Кнопка «Пуск/Стоп»:** Подключите к `PD2` (INT0) с подтяжкой к GND.
    *   **Кнопка «Реверс»:** Подключите к `PD3` (INT1) с подтяжкой к GND.
    *   **Потенциометр (АЦП):** Подключите к `PC0` (ADC0). Средний вывод к ножке МК, крайние к +5В и GND.
7.  **Индикация:**
    *   **7-сегментный индикатор:** Например, с общим катодом. Управляйте сегментами через порт `PD0`, `PD1`, `PD4`... (потребуется решить конфликт ног, проще всего взять свободный порт, например, 4 линии порта `PD` и транзисторные ключи, или всю индикацию вынести на `PORTB`/`PORTC`, а управление двигателем — на оставшийся. Для простоты в Proteus можно подключить сегменты напрямую к оставшимся линиям портов). **Рациональный вариант:** Использовать порт `D` [PD4..PD7] для сегментов (a, b, c, d) и `PB4`, `PB5` для сегментов (e, f), а `PB4` через транзистор для общего катода. *В рамках лабораторной работы я бы рекомендовал взять динамическую индикацию, например, на двух 7-сегментных индикаторах, выведя сегменты на `PORTC`, а ключи катодов на `PB4, PB5`, чтобы показать более серьезный подход*.

### Фрагмент программы на C++ (Atmel Studio)

Этот шаблон демонстрирует работу с таймером, автоматом состояний и обработчиками прерываний для кнопок.

```cpp
#define F_CPU 16000000UL
#include <avr/io.h>
#include <avr/interrupt.h>
#include <util/delay.h>

// Определяем номер текущего шага в массиве
volatile uint8_t current_step = 0;
volatile uint8_t direction = 1; // 1 - по часовой, 0 - против
volatile uint8_t motor_running = 0;
volatile uint16_t step_delay = 10; // Задержка между шагами в мс (от АЦП)

// Битовые маски для L293D (PB0..PB3)
const uint8_t full_step_sequence[4] = {
    0b00001010, // IN4=0, IN3=0, IN2=1, IN1=0
    0b00000110, // 0, 0, 1, 1
    0b00000101, // 0, 1, 0, 1
    0b00001001  // 1, 0, 0, 1
};

// Инициализация портов
void io_init() {
    DDRB |= (1 << PB0) | (1 << PB1) | (1 << PB2) | (1 << PB3); // Выходы на драйвер
    DDRD &= ~((1 << PD2) | (1 << PD3)); // Входы кнопок (INT0, INT1)
    PORTD |= (1 << PD2) | (1 << PD3);  // Подтяжка вверх для кнопок
    
    // Настройка АЦП
    ADMUX |= (1 << REFS0); // Опорное напряжение AVcc
    ADCSRA |= (1 << ADEN) | (1 << ADPS2) | (1 << ADPS1); // Включить АЦП, делитель 64
}

// Функция перемещения на один шаг
void make_step(uint8_t dir) {
    if (dir) { // По часовой
        current_step = (current_step + 1) % 4;
    } else {   // Против часовой
        current_step = (current_step == 0) ? 3 : current_step - 1;
    }
    PORTB = full_step_sequence[current_step];
}

// Прерывание по кнопке PD2 (Пуск/Стоп)
ISR(INT0_vect) {
    motor_running = !motor_running;
    _delay_ms(50); // Упрощенный антидребезг
    EIFR |= (1 << INTF0); // Сброс флага прерывания
}

// Прерывание по кнопке PD3 (Реверс)
ISR(INT1_vect) {
    direction = !direction;
    _delay_ms(50);
    EIFR |= (1 << INTF1);
}

int main(void) {
    io_init();
    
    // Настройка внешних прерываний по низкому уровню (или по спаду, если кнопка к GND)
    EICRA |= (1 << ISC01) | (1 << ISC11); // Прерывание по спаду для INT0 и INT1
    EIMSK |= (1 << INT0) | (1 << INT1);
    
    // Настройка таймера 1 для управления скоростью (CTC режим)
    // ... здесь должен быть код настройки таймера ...
    
    sei(); // Глобально разрешаем прерывания

    while (1) {
        if (motor_running) {
            // Чтение АЦП для задания скорости
            ADCSRA |= (1 << ADSC); // Запуск преобразования
            while (ADCSRA & (1 << ADSC));
            step_delay = ADC / 10 + 10; // Преобразуем значение в задержку 10-112 мс
            
            // Выполняем шаг
            make_step(direction);
            
            // Задержка между шагами (в реальности лучше на таймере)
            for (uint16_t i = 0; i < step_delay; i++) {
                _delay_ms(1);
            }
        }
        // Здесь должен быть код отображения скорости на 7-сегментный индикатор
        // (например, номер шага или условные проценты)
    }
}
```
