# «Управление яркостью светодиодов с использованием ШИМ»

---

## 📌 **Цель работы**

Цель данной лабораторной работы — изучить и закрепить использование технологии ШИМ (широтно-импульсной модуляции) для управления яркостью светодиодов. Работа включает в себя:

* настройку таймеров для работы с ШИМ
* работу с кнопками для управления параметрами ШИМ
* использование прерываний для асинхронного контроля

---

## 📋 **Задание**

### 1. **Управление яркостью светодиодов с помощью ШИМ**

С помощью **ШИМ** (широтно-импульсной модуляции) реализовать управление яркостью светодиода. Светодиод подключается к одному из выводов микроконтроллера, поддерживающих ШИМ.

* **Шаг 1** — настройка ШИМ на выбранном порту для управления яркостью светодиода.
* **Шаг 2** — настройка таймера для работы в режиме ШИМ.
* **Шаг 3** — изменение коэффициента заполнения (Duty Cycle) с помощью кнопок, таким образом, чтобы светодиод становился более ярким или тусклым.

---

### 2. **Режимы работы**

* **Режим 1** — Увеличение яркости. Каждое нажатие кнопки увеличивает коэффициент заполнения ШИМ на 10% (от 0 до 100%).
* **Режим 2** — Уменьшение яркости. Каждое нажатие другой кнопки уменьшает коэффициент заполнения ШИМ на 10% (от 100 до 0%).
* **Режим 3** — Режим автоматической регулировки яркости. Светодиод будет тускнеть и становиться ярче с определённым интервалом времени (реализуется через таймер).

---

### 3. **Индикация**

* **LCD 16x2** — отображение текущего коэффициента заполнения (Duty Cycle).
* **7-сегментный динамический индикатор** — индикация яркости светодиода в процентах.

---

### 4. **Кнопки**

* **Кнопка 1** — увеличение яркости (увеличение Duty Cycle).
* **Кнопка 2** — уменьшение яркости (уменьшение Duty Cycle).
* **Кнопка 3** — активация режима автоматической регулировки яркости.

---

### 5. **Прерывания**

* Использование прерываний для асинхронной обработки кнопок.
* Защита от дребезга кнопок обязательна.

---

### 6. **Ограничения**

* **Использование только таймеров** для работы с ШИМ.
* **Без использования `_delay_ms()`** в основном цикле программы.
* Все логические процессы должны быть асинхронными (с использованием прерываний).

---

## 🔌 **Необходимые компоненты**

1. **Микроконтроллер**: ATmega328P
2. **Светодиоды**: минимум 1 светодиод для управления яркостью
3. **LCD 16x2**: для отображения текущего состояния яркости
4. **7-сегментный индикатор**: для индикации в процентах
5. **Кнопки**: минимум 3 кнопки для управления
6. **Резисторы и транзисторы** для подключения светодиодов и кнопок
7. **Резисторы для ограничения тока на светодиодах**
