# Тема: Использование аналого-цифрового преобразователя (АЦП) и аналоговых датчиков в микроконтроллере ATmega328P

---

## 1. Введение

В ранее изученных лабораторных работах рассматривались устройства, работающие с дискретными (цифровыми) сигналами: светодиоды, кнопки, индикаторы, дисплеи. Однако в реальных технических системах значительная часть информации поступает в виде **аналоговых сигналов**.

Цель данной лекции — изучить принципы работы аналого-цифрового преобразования и освоить методы считывания аналоговых величин с использованием встроенного АЦП микроконтроллера ATmega328P.

## 3. Теоретические сведения

### 3.1. Понятие аналого-цифрового преобразования

Аналого-цифровой преобразователь (АЦП) — это устройство, преобразующее непрерывный аналоговый сигнал (напряжение) в дискретное цифровое значение.

АЦП выполняет:

1. дискретизацию (разбиение сигнала по времени);
2. квантование (разбиение по уровню);
3. кодирование (представление в цифровом виде).

---

### 3.2. Основные характеристики АЦП

АЦП микроконтроллера ATmega328P обладает следующими параметрами:

* разрядность: 10 бит;
* диапазон выходных значений: 0–1023;
* количество каналов: 6 (ADC0–ADC5);
* тип преобразования: последовательное приближение.

---

### 3.3. Связь входного напряжения и цифрового значения

ADC = \frac{V_{in}}{V_{ref}} \cdot 1023

где:
(V_{in}) — входное напряжение;
(V_{ref}) — опорное напряжение;
ADC — результат преобразования.

---

### 3.4. Опорное напряжение

В ATmega328P доступны следующие варианты опорного напряжения:

* AVCC (обычно 5 В);
* внутренний источник (1.1 В);
* внешний источник (через вывод AREF).

Выбор опорного напряжения влияет на точность и диапазон измерений.

---

### 3.5. Аналоговые входы

Аналоговые входы реализованы на выводах порта C:

* PC0 — ADC0
* PC1 — ADC1
* PC2 — ADC2
* PC3 — ADC3
* PC4 — ADC4
* PC5 — ADC5

---

## 4. Используемый датчик

В качестве источника аналогового сигнала используется:

* потенциометр (для отладки и тестирования);
* датчик температуры LM35.

### Основные характеристики LM35:

* линейная зависимость выходного напряжения от температуры;
* коэффициент преобразования: 10 мВ/°C;
* диапазон измерения: от −55°C до +150°C;
* не требует внешней калибровки.

---

## 5. Аппаратная часть (схема подключения)

### 5.1. Подключение потенциометра

* один крайний вывод → VCC;
* второй крайний вывод → GND;
* средний вывод → ADC0 (PC0).

### 5.2. Подключение LM35

* VCC → +5 В;
* GND → GND;
* OUT → ADC0 (PC0).

### 5.3. Дополнительные компоненты

* LCD-дисплей 16×2 (4-битный режим);
* микроконтроллер ATmega328P.

---

## 6. Программная реализация

### 6.1. Настройка АЦП

Основные регистры:

* ADMUX — выбор канала и опорного напряжения;
* ADCSRA — управление работой АЦП.

```cpp
#include <avr/io.h>

void ADC_init() {
    ADMUX = (1 << REFS0); // опорное напряжение AVCC

    ADCSRA = (1 << ADEN)   // включение АЦП
           | (1 << ADPS2) 
           | (1 << ADPS1); // делитель частоты (64)
}
```

---

### 6.2. Чтение данных с АЦП

```cpp
uint16_t ADC_read(uint8_t channel) {
    channel &= 0x07;
    ADMUX = (ADMUX & 0xF8) | channel;

    ADCSRA |= (1 << ADSC); // запуск преобразования

    while (ADCSRA & (1 << ADSC)); // ожидание завершения

    return ADC;
}
```

---

### 6.3. Основной цикл программы

```cpp
#include <util/delay.h>

int main(void) {
    ADC_init();

    while (1) {
        uint16_t value = ADC_read(0);

        // вывод значения на LCD
        _delay_ms(200);
    }
}
```

## 7. Преобразование результата

### 7.1. Напряжение

Напряжение можно вычислить по формуле:

ADC = (Vin / Vref) * 1023

где:

Vin — входное напряжение
Vref — опорное напряжение

---

### 7.2. Температура (для LM35)

T = (ADC * Vref) / (1023 * 0.01)

где:
0.01 В = 10 мВ/°C.
